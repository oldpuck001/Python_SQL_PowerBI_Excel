Markdown语法


# 標題（Heading）

# 一級標題
## 二級標題
### 三級標題
#### 四級標題
##### 五级標題
###### 六级標題


# 文字樣式

**粗體**
*斜體*
***粗斜體***
~~刪除線~~


# 段落與換行

這是一個段落

這是下一個段落  
這一行會強制換行（行尾兩個空格）


# 清單（列表）

## 無序列表

- 項目一
- 項目二
  - 子項目

## 有序列表

1. 第一項
2. 第二項
3. 第三項


# 任務清單（Checklist）

- [x] 已完成
- [ ] 未完成


# 連結（Link）

[OpenAI](https://www.openai.com)


# 圖片（Image）

![圖片說明](https://example.com/image.png)


# 程式碼

## 行內程式碼

使用 `print("Hello")` 輸出內容

## 程式碼區塊

```python
def hello():
    print("Hello Markdown")
```
